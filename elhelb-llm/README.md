# 🚀 ELHELB COMPANY AI — الموديل الذكي الخاص بشركتك (بيانات + جداول + تحليل صور + ربط تطبيق الموبايل)

منظومة ذكاء اصطناعي خاصة بمجموعة الهلب تفتح **مباشرة بدون شاشات باسورد معقدة**، مصممة لتغذيتها بكل بيانات وجداول الشركة، تحليل الصور والفواتير، والربط المباشر مع **تطبيق الموبايل (Mobile App)** مع بقاء جميع معلومات الشركة **معزولة ومشفرة بأمان 100% داخل سيرفرك**.

---

## ✨ الإمكانيات الأساسية

1. **بدون باسورد أو تعقيد — مع تشفير وعزل محلي كامل للبيانات:**
   - تفتح لوحة التحكم والشات فوراً بدون تسجيل دخول.
   - الأمان مبني في البنية التحتية نفسها: جميع وثائق وجداول الشركة تُحفظ مشفرة على القرص بـ **`AES-256-GCM`**، مع جدار عزل **`Air-Gap`** يمنع إرسال أي بيانات لسيرفرات سحابية خارجية.
2. **يحلل كل بيانات وجداول الشركة ويرد على كافة الأسئلة:**
   - أضف لوائح وعقود الشركة النصية (`.txt`, `.md`, `.json`) أو **جداول الأرقام والمبيعات والمخزون (`.csv`, `.json`)**.
   - يحسب الموديل تلقائياً الإجماليات، المتوسطات، ترتيب الفروع والمنتجات الأعلى مبيعاً، وينبّهك فوراً للأصناف التي وصلت لحد الطلب في المخزن.
3. **يستقبل الصور ويحللها (`Multimodal Vision + Offline OCR`):**
   - ارفع أو الصق (`Ctrl+V`) أو صوّر من كاميرا الموبايل أي **فاتورة، عرض سعر، بيان مخزن، أو مستند**.
   - يقرأ المحرك النصوص العربية والإنجليزية والأرقام والنسب من الصورة محلياً بدون إنترنت (`Tesseract LSTM ara+eng` + `Sharp`)، ويطابقها فوراً مع قواعد وأسعار الشركة (ويدعم كذلك موديلات الرؤية المحلية مثل `llama3.2-vision` و `qwen2.5vl` عبر Ollama).
4. **جاهز للربط المباشر مع تطبيق الموبايل (`Flutter` / `React Native` / `Kotlin`):**
   - يضم تبويب **«📱 الربط مع تطبيق الموبايل»** محاكي موبايل تفاعلي حي، وأكواد جاهزة للنسخ واللصق لتطبيقك:
     - `POST /api/v1/chat` — إرسال سؤال أو صورة كاميرا (`multipart/form-data` أو `imageBase64`) واستلام التحليل الكامل.
     - `POST /api/v1/vision/analyze` — نقطة مخصصة لتحليل الصور والفواتير من الموبايل.
     - `POST /api/v1/data/ingest` — إضافة بيانات جديدة للشركة من التطبيق.
     - `POST /v1/chat/completions` — متوافق 100% مع حزم `OpenAI SDK` الجاهزة في الموبايل (يدعم النصوص والصور).

## ⚡ التشغيل السريع

```bash
cd elhelb-llm
npm install
npm run build
npm start
```
يعمل السيرفر والواجهة وروابط الـ Mobile API على: `http://localhost:4000`

### تشغيل موديلات Ollama المحلية على سيرفر الشركة (اختياري لذكاء لغوي وبصري أعمق بدون إنترنت):
```bash
ollama pull qwen2.5:7b
ollama pull llama3.2-vision
```

### تشغيل الاختبارات الآلية:
```bash
npm test
```
