# 🧠 دليل بناء وتدريب الموديل الخاص بشركتك (بدون تسريب بيانات)

لما أي شركة تحب تعمل **LLM خاص بيها وبياناتها في أمان 100%**، فيه 3 طبقات بيكمّلوا بعض — وكلهم مبنيين في المشروع ده:

| الطبقة | فايدتها | إمتى تستخدمها؟ |
|---|---|---|
| **1. تشغيل موديل مفتوح المصدر محلياً (Ollama + Qwen2.5)** | الموديل بيشتغل على جهاز/سيرفر الشركة الداخلي، ولا كلمة بتطلع لـ OpenAI أو جوجل | **أساسي دايماً** للأمان والخصوصية |
| **2. خزنة المعرفة المشفرة وعزل الأقسام (Private Encrypted RAG)** | بترفع عقودك ولوائحك وأسعارك (مشفرة بـ `AES-256-GCM`) والموديل يقرأ منها لحظياً حسب صلاحية كل موظف | **الأهم للأرقام واللوائح المتجددة** (تتحدث في ثانية بدون إعادة تدريب) |
| **3. التدريب المخصص (QLoRA Fine-Tuning)** | بتعلّم أوزان الموديل نفسها أسلوب صياغة شركتك ومصطلحاتها الخاصة | لما تحب الموديل يحفظ **نبرة وأسلوب وقوالب** الشركة في مخه |

---

## ⚡ الطريقة الأولى (الأسرع — في 3 دقايق على جهاز الشركة)

1. نزّل **Ollama** على سيرفر أو جهاز الشركة من الموقع الرسمي.
2. اسحب أقوى موديل مفتوح المصدر بيدعم العربي بطلاقة (مرة واحدة بس وبعدها افصل الإنترنت لو حابب):
   ```bash
   ollama pull qwen2.5:7b
   ollama create elhelb-gpt-v1 -f Modelfile
   ```
3. افتح واجهة **ELHELB Private AI**، وهتلاقيه لقط الموديل المحلي أوتوماتيك واشتغل عليه مع خزنة البيانات المشفرة!

---

## 🔬 الطريقة الثانية (تدريب الأوزان نفسها بـ QLoRA — `train_lora.py`)

لو عندك كارت شاشة NVIDIA (من أول `RTX 3060 12GB` أو `RTX 4060 Ti 16GB` أو سيرفر خاص معزول):

1. من تبويب **«مصنع بناء وتدريب الموديل»** في الموقع، راجع أمثلة التدريب ودوس **تحميل ملف JSONL (ShareGPT)** واحفظه جنب السكريبت باسم `elhelb_finetune_sharegpt.jsonl`.
2. ثبّت المكتبات وشغّل التدريب:
   ```bash
   cd training
   pip install -r requirements.txt
   python3 train_lora.py --dataset ./elhelb_finetune_sharegpt.jsonl --epochs 3
   ```
   > 🔒 السكريبت مضبوط على `report_to="none"` عشان ميبعتش أي بيانات تدريب لأي خدمة مراقبة سحابية!
3. بعد ما يخلص، هيطلعلك ملف `.gguf` جاهز — شغّله في Ollama بأمر واحد وبقى عندك موديل بأوزان شركتك 100%!
