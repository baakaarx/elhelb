# ELHELB GROUP — مشاريع مجموعة الهلب

- **[`elhelb-boards/`](./elhelb-boards)** — نظام إدارة المهام واللوحات المؤسسي (شبيه Trello) بنظام الأدوار والصلاحيات الديناميكية من قاعدة البيانات، عزل الأقسام، وطلبات الاستثناء من المدير.
- **[`elhelb-workers/`](./elhelb-workers)** — بوابة تسجيل بيانات العاملين والموارد البشرية.
- **[`my-agent/`](./my-agent)** — مشروع الذكاء الاصطناعي التعليمي (ELHELP AI).
