# 🤖 ELHELP AI — الايجنت الشخصي بتاعك (مشروع تعليمي)

مشروع بسيط يعلّمك إزاي تبني **AI Agent** حقيقي من الصفر، من غير أي مكتبات أو فريموركات — JavaScript خام عشان تشوف كل حاجة بتحصل إزاي.

---

## 🎯 إيه الفرق بين "شات بوت" و"ايجنت"؟

| شات بوت | ايجنت |
|---|---|
| بيرد على كلامك وخلاص | بياخد **قرارات** وبينفذ **أدوات** |
| ملوش ذاكرة | عنده ذاكرة قصيرة وطويلة المدى |
| خطوة واحدة: سؤال → جواب | **لووب**: يفكر → ينفذ أداة → يشوف النتيجة → يكمل |

المعادلة السحرية:

```
ايجنت = موديل لغوي (LLM) + أدوات (Tools) + لووب (Loop) + ذاكرة (Memory)
```

## 🔑 أول خطوة: هات مفتاح API مجاني (دقيقتين)

### الخيار 1: Groq (الأسرع — مُوصى به)
1. ادخل على [console.groq.com](https://console.groq.com) وسجّل بحساب جوجل
2. من القايمة اختار **API Keys** → **Create API Key**
3. انسخ المفتاح وحطه في ⚙️ الإعدادات في الصفحة

### الخيار 2: Google Gemini
1. ادخل على [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. دوس **Create API Key**
3. انسخه وحطه في ⚙️ الإعدادات واختار "Gemini" من القايمة

> 🔒 المفتاح بيتحفظ في متصفحك بس (localStorage) والطلبات بتروح من متصفحك للمزوّد مباشرة.
> ده تمام لمشروع تعليمي شخصي — لكن في منتج حقيقي للناس، المفتاح لازم يقعد على سيرفر وسيط (زي ما عملنا في مشروع elhelb بالظبط).

## ⚙️ إزاي الايجنت شغال؟ (الـ 4 مفاهيم الأساسية)

### 1. الذاكرة قصيرة المدى (Conversation History)
الموديلات اللغوية **ملهاش ذاكرة خالص** — كل طلب بيتبعت لوحده كأنها أول مرة.
الحل: بنبعت المحادثة كلها (آخر 30 رسالة عندنا) مع كل طلب جديد.

### 2. الذاكرة طويلة المدى (Long-term Memory) — أهم فكرة في المشروع
- عندنا أداة اسمها `save_memory`
- الـ system prompt بيقول للموديل: "لو المستخدم قال معلومة عن نفسه، احفظها"
- **الموديل نفسه بيقرر** يحفظ إيه وإمتى
- المحفوظات بتتحقن تاني في الـ system prompt في كل محادثة
- النتيجة: تقفل الصفحة وترجع بعد أسبوع، يفتكرك 🧠

### 2.5 قاعدة المعرفة — "علّمه أي حاجة" (RAG مبسط) 📚
دي أشهر تقنية في عالم الايجنتس واسمها **RAG** (Retrieval Augmented Generation):
- بتعلّم الايجنت معلومات بـ 3 طرق: زرار **➕ علّمه حاجة**، أو **📄 رفع ملف نصي**، أو تقوله في الشات "اتعلم إن..."
- المعلومات بتتحفظ كمواضيع (عنوان + محتوى)، والملفات الكبيرة بتتقسم **أجزاء (chunks)**
- **مش** بنحقن كل المعرفة في الـ prompt (هتبقى ضخمة وغالية) — بنحقن العناوين بس
- لما تسأله، بيستخدم أداة `search_knowledge` يدوّر بيها ويقرأ المحتوى المناسب بس، ويبني رده عليه

> البحث عندنا بالكلمات المفتاحية (بسيط ومفهوم). الأنظمة الكبيرة بتستخدم **embeddings** — تمثيل رقمي للمعنى بيلاقي النتايج حتى لو الكلمات مختلفة. دي ترقيتك الجاية.

### 3. الأدوات (Tool / Function Calling)
بنوصف كل أداة بـ JSON Schema (اسمها، بتعمل إيه، بتاخد إيه).
الموديل مش بينفذ حاجة بنفسه — هو بيرجّع "أنا عايز أنادي الأداة الفلانية بالقيم دي"،
وإحنا اللي بننفذ وبنرجعله النتيجة. (شوف `executeTool` في agent.js)

### 4. اللووب (The Agent Loop) — قلب أي ايجنت ❤️
```
┌─> ابعت المحادثة للموديل
│     ├── رد بكلام؟ → اعرضه وخلصنا ✅
│     └── طلب أداة؟ → نفذها → حط النتيجة في المحادثة ─┐
└──────────────────────────────────────────────────────┘
          (بحد أقصى 5 لفات عشان ميعلّقش)
```
ده **بالظبط** نفس التصميم اللي شغال بيه ChatGPT وClaude وأي ايجنت كبير — بس هما عندهم أدوات أكتر وموديلات أقوى.

## 💪 تمارين تطوّر بيها نفسك (بالترتيب)

1. **سهل**: ضيف أداة `random_number` بترجع رقم عشوائي بين حدين
2. **سهل**: خلي الايجنت يحفظ لون المحادثة المفضل ويغيّر الثيم فعلاً
3. **متوسط**: ضيف أداة `forget_memory` عشان الموديل يمسح معلومة قديمة لو المستخدم صحّحها
4. **متوسط**: ضيف streaming — خلي الرد يظهر كلمة كلمة (`stream: true` في الطلب)
5. **متوسط**: حسّن بحث المعرفة — خليه يتجاهل "ال" التعريف والتشكيل عشان يلاقي أكتر
6. **صعب**: انقل نداء الموديل لسيرفر Express (زي elhelb) عشان المفتاح ميبقاش في المتصفح
7. **صعب**: استبدل البحث بالكلمات بـ **embeddings** حقيقية (Gemini عنده embeddings API مجاني)

لما تخلّص التمارين دي، هتكون فاهم الايجنتس أحسن من 90% من الناس اللي بتتكلم عنها 😉
