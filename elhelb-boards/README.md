# 🏢 ELHELB GROUP — منصة إدارة المهام واللوحات بنظام الصلاحيات الديناميكية (ELHELB BOARDS)

نظام مؤسسي متكامل لإدارة المهام واللوحات بنظام كانبان مصمم خصيصاً لـ **مجموعة الهلب (ELHELB GROUP)**، يعمل بنظام **صلاحيات ديناميكية مخزنة بالكامل في قاعدة البيانات** مع **عزل صارم لأقسام الشركة الـ 8**، **تسجيل موظفين عبر Google & Facebook واعتماد رئيس القسم**، و**ربط إشعارات البريد عبر Gmail**.

---

## ✨ المميزات الرئيسية

1. **صلاحيات ديناميكية 100% من قاعدة البيانات (بدون تعديل الكود)**:
   - جميع الأدوار (`roles`) والصلاحيات (`permissions`) ومصفوفة الربط (`role_permissions`) محفوظة في قاعدة البيانات.
   - هرمية سيادية محمية: `رئيس مجلس الإدارة` (رتبة 100) ← `المدير العام` (90) ← `مسؤول تكنولوجيا المعلومات IT` (80) ← `رئيس قسم` (60) ← `مشرف فريق` (40) ← `موظف تنفيذي` (20) ← `متدرب / مشاهد` (10).
2. **عزل كامل بين أقسام الشركة الـ 8 (Department Isolation)**:
   - الأقسام المعتمدة: **التصدير والشحن الدولي**، **تسجيل المنتجات والتراخيص**، **تكنولوجيا المعلومات (IT)**، **المبيعات والتعاقدات**، **المشتريات والتوريدات**، **الميديا والتسويق**، **الموارد البشرية**، و**الحسابات والمالية**.
   - كل موظف يرى فقط لوحات القسم التابع له، مع تحقق أمني إلزامي على السيرفر في كل طلب HTTP لمنع التلاعب بمعرفات اللوحات أو الكروت (**IDOR**).
3. **بوابة انضمام الموظفين عبر Google & Facebook (3 خطوات)**:
   - يسجل الموظف الجديد عبر حسابه في **Google** أو **Facebook** بالاسم والبريد الحقيقي.
   - **الخطوة 1:** ينشئ اسم مستخدم وكلمة مرور خاصة به للدخول المباشر مستقبلاً.
   - **الخطوة 2:** يحدد القسم التابع له في الشركة.
   - **الخطوة 3:** ينتظر اعتماد **رئيس القسم** أو مسؤول النظام ليتم تسكينه وفتح لوحات قسمه تلقائياً.
4. **نظام طلبات تجاوز الصلاحيات من المدير (Permission Elevation Workflow)**:
   - إرسال طلب إذن مؤقت للمدير عند الحاجة لإجراء يتجاوز صلاحيات الدور، مع دعم الموافقة لمرة واحدة فقط أو لفترة زمنية محددة وإمكانية السحب الفوري.
5. **ربط إشعارات Gmail الرسمي (`smtp.gmail.com`)**:
   - إرسال إشعارات عربية منسقة (RTL) تلقائياً عند تسجيل موظف جديد، اعتماد تسكينه بالقسم، طلبات الصلاحيات، وإسناد المهام، مع لوحة إعدادات واختبار فوري من شاشة الإدارة.

## 🚀 التشغيل المحلي والنشر على Vercel

يتطلب **Node.js 22+**:

```bash
cd elhelb-boards
npm install
npm run build
npm start
```

لتشغيل اختبارات الأمان وعزل الأقسام والصلاحيات الآلية:

```bash
npm test
```

### إعدادات النشر على Vercel
- **Root Directory:** `elhelb-boards`
- **Build Command:** `npm run build`
- **Output Directory:** `public`

## 🔐 الحسابات والأمان في وضع الإنتاج

يعمل النظام في وضع الإنتاج النظيف بحساب سيادي واحد فقط خاص برئيس مجلس الإدارة (`admin`) بدون أي حسابات تجريبية أو قوائم دخول سريع، ويتم إنشاء أو اعتماد حسابات رؤساء الأقسام والموظفين حصرياً عبر لوحة الإدارة أو بوابة التسجيل الرسمية.
