# 🏢 ELHELB GROUP — منصة إدارة المهام واللوحات بنظام الصلاحيات الديناميكية (ELHELB BOARDS)

نظام مؤسسي متكامل لإدارة المهام واللوحات بنظام كانبان مصمم خصيصاً لـ **مجموعة الهلب للصناعات الكيماوية والزراعية (ELHELB GROUP)**، يعمل بنظام **صلاحيات ديناميكية مخزنة بالكامل في قاعدة البيانات** مع **عزل صارم لأقسام الشركة الـ 14**، **تسكين الموظفين عبر إدارة الموارد البشرية (HR)**، و**ربط إشعارات البريد عبر Gmail**.

---

## ✨ المميزات الرئيسية

1. **صلاحيات ديناميكية 100% من قاعدة البيانات (بدون تعديل الكود)**:
   - جميع الأدوار (`roles`) والصلاحيات (`permissions`) ومصفوفة الربط (`role_permissions`) محفوظة في قاعدة البيانات.
   - هرمية سيادية محمية: `رئيس مجلس الإدارة` (رتبة 100) ← `المدير العام` (90) ← `مسؤول تكنولوجيا المعلومات IT` (80) ← `مسؤول الموارد البشرية HR` (70) ← `رئيس قسم` (60) ← `مشرف فريق` (40) ← `موظف تنفيذي` (20) ← `متدرب / مشاهد` (10).
2. **عزل كامل بين أقسام الشركة الـ 14 (Department Isolation + Sovereign Office)**:
   - التصدير والشحن الدولي، تسجيل المنتجات والتراخيص، تكنولوجيا المعلومات (IT)، المبيعات والتعاقدات، المشتريات والتوريدات، الميديا والتسويق، الموارد البشرية (HR)، الحسابات والمالية، التخليص الجمركي واللوجستيات والموانئ، المصانع والإنتاج والتعبئة، المعامل ورقابة الجودة (QC)، المخازن وإدارة الإمداد، الدعم الفني الزراعي والتجارب الحقلية، بالإضافة إلى قسم الذكاء الاصطناعي وتطوير الأنظمة (AI) ذي الخصوصية السيادية.
3. **نظام تسكين الموظفين عبر الـ HR وإلغاء حسابات تاركي العمل**:
   - يسجل الموظف الجديد اسمه واسم المستخدم وكلمة المرور مباشرة ويختار قسمه، ثم يعتمد الـ HR أو رئيس مجلس الإدارة تسكينه مع الحفاظ الكامل على لوحات ومهام القسم عند حذف أي موظف يترك العمل.
4. **جاهزية كاملة للسيرفرات الخاصة والتعديل الحي (`Live Edit`)**:
   - مثبّت آلي لسيرفرات Linux (`setup-from-zip.sh` و `deploy/install-server.sh`)، ومشغّل لسيرفرات Windows (`start-windows-server.bat`)، ودعم كامل لـ Docker (`docker compose up -d --build`)، ونظام نسخ احتياطي واستعادة بضغطة واحدة لرئيس مجلس الإدارة.

## 🚀 التشغيل السريع (يتطلب Node.js 22 LTS)

```bash
cd elhelb-boards
npm ci
npm run build
npm start
```

ولقسم الـ IT عند الرفع على سيرفر الشركة، راجع الملف المرفق: **`IT_SERVER_GUIDE_AR.md`**.
