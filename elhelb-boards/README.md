# 🏢 ELHELB GROUP — نظام إدارة المهام واللوحات بنظام الصلاحيات الديناميكية (RBAC)

نظام مؤسسي متكامل لإدارة المهام واللوحات على غرار **Trello** مصمم خصيصاً لـ **مجموعة الهلب (ELHELB GROUP)**، مبني بنظام **صلاحيات ديناميكية مخزنة بالكامل في قاعدة البيانات (SQLite)** مع **عزل صارم للأقسام** و**تحقق أمني على السيرفر في كل طلب** و**نظام طلبات استثناء الصلاحيات من المدير**.

---

## ✨ المميزات الرئيسية

1. **صلاحيات ديناميكية 100% من قاعدة البيانات (بدون تعديل الكود)**:
   - جميع الأدوار (`roles`) والصلاحيات (`permissions`) ومصفوفة الربط (`role_permissions`) محفوظة في قاعدة بيانات علاقية.
   - يمكن للمدير العام إنشاء أدوار جديدة أو تعديل صلاحيات أي دور من شاشة **إدارة الصلاحيات والنظام**، وتُطبَّق التغييرات فوراً في الطلب التالي دون إعادة تشغيل السيرفر.
2. **عزل كامل بين أقسام الشركة (Department Isolation)**:
   - كل لوحة عمل ترتبط بقسم محدد (**المبيعات**، **الميديا والتسويق**، **المشتريات والتوريدات**، **الموارد البشرية**، إلخ).
   - كل موظف يرى فقط لوحات القسم التابع له، ولا يمكنه رؤية لوحات أو كروت الأقسام الأخرى حتى لو حاول استدعاء الـ API مباشرة.
3. **حماية حقيقية على مستوى السيرفر (Zero-Trust Server Enforcement)**:
   - يتحقق السيرفر في كل مسار (`/api/...`) من هوية المستخدم وحالة حسابه ودوره وقسمه الفعلي في قاعدة البيانات، ويمنع هجمات التلاعب بمعرفات الكروت أو القوائم (**IDOR**).
   - يضم النظام شاشة **مختبر فحص أمان السيرفر** لإرسال طلبات HTTP حقيقية ومشاهدة حجب السيرفر الفوري بـ `HTTP 403`.
4. **نظام طلبات تجاوز الصلاحيات من المدير (Permission Elevation Workflow)**:
   - عندما يحتاج الموظف إلى تنفيذ إجراء يتجاوز صلاحياته (مثل حذف كارت مكرر، إنشاء لوحة، نقل مهمة، أو الاطلاع المؤقت على قسم آخر)، يمكنه إرسال **طلب إذن للمدير** موضحاً السبب والمدة المقترحة.
   - يراجع **مدير القسم** طلبات موظفي قسمه (في حدود صلاحياته)، بينما تذهب الطلبات العابرة للأقسام تلقائياً إلى **المدير العام**.
   - يمكن للمدير الموافقة بصلاحية **لمرة واحدة فقط** (تُستهلك تلقائياً فور التنفيذ) أو لمدة زمنية محددة (`ساعة`، `8 ساعات`، `24 ساعة`، `7 أيام`)، مع إمكانية **سحب الصلاحية فوراً** في أي لحظة.
5. **تجربة كانبان احترافية متكاملة (Trello Experience)**:
   - سحب وإفلات سلس للكروت بين القوائم، تصنيفات ملونة، درجات أولوية، تواريخ استحقاق وتنبيه التأخير، تعيين أعضاء القسم، قوائم مهام فرعية بنسبة إنجاز، تعليقات الفريق، وبحث فوري آمن.

## 🚀 التشغيل

يتطلب **Node.js 22+** (يستخدم محرك `node:sqlite` المدمج بدون الحاجة لتثبيت قواعد بيانات خارجية):

```bash
cd elhelb-boards
npm install
npm run build
npm start
```

يعمل السيرفر افتراضياً على المنفذ `http://localhost:3000`.

لتشغيل اختبارات الأمان وعزل الأقسام والصلاحيات الآلية:

```bash
npm test
```
